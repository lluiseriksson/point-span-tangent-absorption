# Point-span tangent absorption

This public research repository contains two frozen, reproducible manuscripts
on lower bounds for finite point spans that absorb embedded tangent spaces.

## Papers

| Version | Role | Main scope | PDF |
|---|---|---|---|
| [`successor_v0.1`](successor_v0.1/) | Current paper | Characteristic-free bounds and sharp Gauss-fiber examples | [`paper.pdf`](successor_v0.1/paper.pdf) |
| [`v0.5`](v0.5/) | Reviewed predecessor | Characteristic-zero Gauss-branch unisolvence and corrected uniform bounds | [`paper.pdf`](v0.5/paper.pdf) |

Each folder is a frozen package with source, PDF, exact finite replays,
review/audit records, a SHA-256 manifest, and a deterministic ZIP. The package
verifiers check those frozen payloads independently of this repository-level
documentation.

## Verification

GitHub Actions verifies both package manifests, runs every shipped exact finite
fixture, and compiles both LaTeX manuscripts. The finite fixtures certify only
their displayed matrices; they do not by themselves prove universal theorems,
Bertini arguments, novelty, or priority.

The successor received an independent post-correction referee score of
`6.8/10.0 +/- 0.7`; this is an audit result, not peer review or journal
acceptance. The repository makes no Millennium-problem claim.
