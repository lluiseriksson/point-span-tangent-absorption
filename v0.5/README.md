# Reviewed predecessor v0.5

This directory publishes the reviewed predecessor
*Rank Bounds and a Gauss-Fiber Alternative for Point-Span Tangent Absorption*.

The deterministic ZIP is the authoritative frozen package. It contains the
complete source, PDF, replay scripts and results, response to review, build
report, workflow snapshot, and SHA-256 manifest. Selected top-level files are
duplicated here for convenient browsing.

runs all exact finite fixtures, and recompiles the manuscript. The fixtures
certify only the listed finite calculations, not the universal theorem,
novelty, or priority.
